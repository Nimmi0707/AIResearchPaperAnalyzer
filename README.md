# AI Research Paper Analyzer

An interactive web application for analyzing and exploring academic research papers using AI-assisted technologies.

## 🚀 Features

- 📄 Research paper analysis
- 📊 Interactive research insights dashboard
- 📝 Abstract and key findings extraction
- 🔑 Keyword analysis and visualization
- 🔬 Methodology analysis
- 📈 Results visualization
- 💬 Ask My Paper — interactive paper Q&A
- 🔄 Compare two research papers
- 📥 Downloadable analysis report
- 🌙 Dark/Light mode
- 📱 Responsive UI
- 🎨 Modern academic AI interface

## 🛠️ Tech Stack

- React.js
- TypeScript
- Vite
- Tailwind CSS
- JavaScript
- Lucide Icons
